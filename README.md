## CogniCare
Proyek Analisis Kesehatan Mental & Kebiasaan Digital Coding Camp powered by DBS Foundation

## Deskripsi Singkat Proyek
CogniCare adalah proyek analisis data yang bertujuan untuk menganalisis hubungan antara kebiasaan digital (seperti screen time) dengan tingkat kelelahan kognitif dan kesehatan mental pengguna. Proyek ini mencakup proses EDA, preprocessing, hingga pemodelan Machine Learning untuk memprediksi fatigue_level seseorang (refreshed / strained / near-burnout).
